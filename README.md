# ann-dl

Exercises for the Artificial Neural Networks and Deep Learning elective (Insper).

Published site: https://stefanolinden.github.io/ann-dl/

## Structure

- `docs/exercises/data/index.md` — report for Exercise 1 (Data)
- `docs/exercises/data/code/` — Python scripts that generate every figure and number used in the report
- `docs/exercises/data/figures/` — generated figures
- `docs/exercises/data/data/train.csv` — Spaceship Titanic dataset (Kaggle)

## Running the code

```bash
pip install -r requirements.txt
cd docs/exercises/data/code
python ex1_point_clouds.py
python ex2_nonlinearity.py
python ex3_preprocessing.py
```
